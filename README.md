# Programação do Zero ao Full Stack

Plataforma pessoal de estudos para aprender programação desde a lógica até desenvolvimento Full Stack, usando **Visual Studio Code como ambiente padrão**.

## Ordem principal da formação

1. Lógica de Programação
2. Python do Zero
3. Python Intermediário e POO
4. Java do Zero
5. Terminal, Git e GitHub
6. HTML e CSS
7. JavaScript
8. ReactJS
9. Internet, HTTP e APIs
10. Back-end com Python e FastAPI
11. Banco de Dados e SQL
12. Full Stack
13. Redes
14. Linux
15. Deploy, Domínios e DNS
16. Segurança
17. Criptografia e Projeto Final

## Estado atual

O site foi reestruturado para **140 aulas implementadas em 15 módulos**, com o módulo de **ReactJS planejado como etapa própria**.

A principal mudança foi inserir **Java imediatamente depois de Python**, sem remover o conteúdo anterior. As antigas aulas posteriores foram renumeradas em tempo de execução para preservar a sequência de aprendizagem.

A base do aplicativo inclui:

- Início;
- Curso;
- Tarefas;
- Vídeos;
- Obsidian;
- Progresso;
- lógica de programação como primeira base;
- Python como primeira linguagem;
- Java como segunda linguagem;
- JavaScript e React para desenvolvimento front-end;
- Python/FastAPI para back-end;
- SQL e banco de dados;
- módulos de redes, Linux, deploy, segurança e criptografia;
- progresso persistente no navegador;
- tarefas persistentes;
- dicas e soluções escondidas;
- integração básica com Obsidian;
- layout responsivo.

## VS Code

Todas as práticas devem ser adaptadas ao VS Code sempre que possível. O terminal integrado do VS Code é o terminal padrão dos exemplos do curso.

Python permanece como linguagem principal para automação, fundamentos e back-end. Java é aprendido como segunda linguagem completa. JavaScript e React permanecem nas tecnologias próprias do front-end em vez de serem convertidos para Python.

## Como abrir

O aplicativo é estático e não exige instalação de dependências web.

1. Baixe ou clone o repositório.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use um servidor HTTP local simples.

## Cursos externos

Playlists e cursos externos podem ser usados como referência de sequência pedagógica, mas o conteúdo desta plataforma deve ser original. Não devem ser feitas transcrições integrais. Conteúdos repetidos devem ser mesclados e atualizados.
