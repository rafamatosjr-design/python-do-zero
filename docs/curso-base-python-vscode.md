# Curso-base — Lógica + Python com VS Code

Este documento substitui a abordagem antiga do módulo inicial por uma trilha integrada baseada em duas referências externas do Curso em Vídeo, **sem copiar/transcrever integralmente as aulas**. O conteúdo do aplicativo deve ser reescrito com linguagem própria, exercícios próprios e exemplos executados no **Visual Studio Code**.

## Referências pedagógicas

1. Curso de Algoritmos — referência para lógica, sequência, variáveis, operadores, decisões, repetições, vetores/matrizes e funções.
2. Curso Python 3 — Mundo 1: Fundamentos — referência para introdução prática ao Python 3.

## Regra principal de adaptação

- Não utilizar Visualg/Portugol como ambiente principal.
- Toda demonstração prática deve ser convertida para Python 3.
- Todo código deve ser criado e executado no Visual Studio Code.
- Portugol/pseudocódigo pode aparecer apenas como ferramenta conceitual curta quando ajudar a explicar a lógica.
- Não reproduzir falas ou transcrições do material original.
- Produzir explicações, exemplos, exercícios e desafios próprios.

## Ambiente padrão

Fluxo de prática em todas as aulas:

1. Abrir o VS Code.
2. Abrir a pasta do curso.
3. Criar um arquivo `.py` para a aula.
4. Digitar o código.
5. Salvar.
6. Abrir o terminal integrado.
7. Executar com `python nome_do_arquivo.py` ou `python3 nome_do_arquivo.py` quando necessário.
8. Ler a saída e corrigir eventuais erros.
