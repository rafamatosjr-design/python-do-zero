# Revisão final — interface e progresso

Ajustes desta etapa:

- usar a última aula aberta como continuidade quando ela ainda não estiver concluída;
- manter a primeira aula não concluída como recomendação quando a última já estiver concluída;
- mostrar corretamente o estado da tarefa dentro da página da aula;
- detalhar o progresso por módulo;
- manter progresso baseado apenas em conclusão explícita;
- usar rolagem padrão compatível ao trocar de rota.
