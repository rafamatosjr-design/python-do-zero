# PROGRAMAÇÃO DO ZERO AO FULL STACK — CURRÍCULO OFICIAL

## 1. Sobre a formação

**Nível inicial:** absoluto iniciante  
**Ambiente padrão:** Visual Studio Code  
**Total atual:** 140 aulas implementadas + módulo React planejado  
**Linguagens principais:** Python, Java e JavaScript

Este arquivo define a nova ordem oficial da formação. A lógica de programação vem antes de qualquer aprofundamento em linguagem.

## 3. Regras pedagógicas

- VS Code é o ambiente padrão de prática.
- Lógica de programação deve ser ensinada antes de sintaxe avançada.
- Python é a primeira linguagem principal.
- Java vem imediatamente depois de Python.
- JavaScript permanece como linguagem da Web; não deve ser convertido para Python.
- React permanece em JavaScript/React.
- Back-end e APIs serão priorizados em Python com FastAPI.
- Cursos externos servem como referência pedagógica e complemento; o conteúdo do projeto deve ser original, reorganizado e atualizado.
- Conteúdos repetidos entre cursos devem ser mesclados, não duplicados.
- Comparações Python → Java e Python → JavaScript devem ser usadas quando ajudarem um iniciante.

## 4. Módulos

### Módulo 1 — Lógica de Programação + Python do Zero
**Aulas 1–20**

Algoritmos, pensamento computacional, entrada/processamento/saída, VS Code, `print`, variáveis, tipos, `input`, operadores, strings, módulos, condições, `for`, `while`, listas, tuplas, conjuntos, dicionários, funções e projeto de sistema escolar no terminal.

### Módulo 2 — Python Intermediário e POO
**Aulas 21–30**

Organização com funções, módulos, arquivos, JSON, exceções, classes, objetos, atributos, métodos, `self`, `__init__`, encapsulamento e projeto orientado a objetos.

### Módulo 3 — Java do Zero no VS Code
**Aulas 31–50**

JDK/JVM, preparação do VS Code, primeiro programa, tipos, entrada e saída, operadores, `if`, `switch`, `for`, `while`, arrays, métodos, classes, objetos, construtores, encapsulamento, herança, polimorfismo, interfaces, coleções, exceções e projeto escolar em Java.

### Módulo 4 — Terminal, Git e GitHub
**Aulas 51–55**

Terminal integrado do VS Code, navegação, arquivos, Git, staging, commits, GitHub, remotos, `.gitignore`, branches, merge e conflitos introdutórios.

### Módulo 5 — Desenvolvimento Web: HTML, CSS e JavaScript
**Aulas 56–70**

HTML semântico, formulários, acessibilidade, CSS, responsividade, Flexbox, Grid, JavaScript, DOM, eventos, validação e projeto front-end.

### Módulo 6 — ReactJS
**Planejado**

Componentes, JSX, props, state, eventos, hooks, formulários, rotas, consumo de APIs e projeto React. O conteúdo será incorporado sem duplicar JavaScript básico.

### Módulo 7 — Internet, HTTP e APIs
**Aulas 71–80**

Cliente/servidor, URLs, IP, portas, HTTP/HTTPS, request/response, REST, métodos HTTP, JSON, códigos de status e consumo de APIs.

### Módulo 8 — Back-end com Python e FastAPI
**Aulas 81–90**

Ambiente Python, FastAPI, rotas, path/query parameters, request body, Pydantic, CRUD, respostas HTTP, organização e fundamentos de API REST.

### Módulo 9 — Banco de Dados e SQL
**Aulas 91–100**

Modelagem relacional, DER, tabelas, chaves, SQL, `SELECT`, `INSERT`, `UPDATE`, `DELETE`, filtros, agregações, `JOIN`, relacionamentos e integração com aplicações. MySQL e PostgreSQL podem ser usados conforme o conteúdo prático.

### Módulo 10 — Full Stack
**Aulas 101–105**

Integração entre front-end, API Python e banco de dados, autenticação introdutória, fluxo de dados e projeto completo.

### Módulo 11 — Redes de Computadores
**Aulas 106–115**

OSI, TCP/IP, IP, sub-redes, IP público/privado, portas e protocolos como HTTP/HTTPS, DNS, TCP/UDP, ICMP e SSH.

### Módulo 12 — Linux
**Aulas 116–120**

Sistema de arquivos, diretórios, permissões, manipulação de arquivos, processos e terminal.

### Módulo 13 — Deploy, Domínios e DNS
**Aulas 121–130**

Hospedagem, servidores, publicação de aplicações, variáveis de ambiente, domínio, DNS e fundamentos de produção.

### Módulo 14 — Segurança da Informação e Aplicações
**Aulas 131–135**

Princípios defensivos, autenticação, proteção de credenciais, riscos comuns, boas práticas de aplicações e fundamentos de segurança.

### Módulo 15 — Criptografia e Projeto Final
**Aulas 136–140**

Conceitos de criptografia, hash, proteção de dados e projeto final integrando os conhecimentos da formação.

## 5. Cursos externos já definidos como referência

A formação poderá aproveitar a progressão pedagógica das playlists fornecidas pela usuária para lógica/algoritmos, Python, Git/GitHub, JavaScript, React, SQL e APIs. O material final deve ser reescrito de forma original e adaptado ao VS Code. Quando a tecnologia original for compatível com Python e fizer sentido pedagógico, a implementação pode ser convertida para Python; tecnologias próprias do front-end, como JavaScript e React, permanecem em sua linguagem adequada.

## 6. Estrutura obrigatória de cada aula

Cada aula deve conter, sempre que aplicável: objetivos, importância, pré-requisitos, explicação simples, exemplo cotidiano, exemplo de programação, código, explicação linha por linha, prática no VS Code, exercício, desafio, encontre o erro, erros comuns, resumo, checklist, tarefa, vídeo complementar e referências.
